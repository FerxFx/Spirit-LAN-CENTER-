Ayuda: cierre de caja

¿Para qué sirve esta sección?

¿?

Permite revisar y guardar el resumen de las ventas de una fecha. El reporte muestra los cobros, los ingresos de Internet y cafetería, los totales por método de pago, el dinero recibido, el vuelto y el detalle de cada venta.

  • Selecciona una fecha para consultar su reporte y usa Cerrar / Actualizar caja para guardar o actualizar el cierre con las ventas registradas ese día.
  • Al cerrar la fecha operativa actual, el sistema inicia automáticamente el siguiente día. También realiza el cierre automático al cambiar el día a medianoche.
  • Los cierres guardados muestran la fecha y hora del dispositivo. Solo un administrador puede borrar un cierre; las ventas se conservan y el día puede cerrarse nuevamente.

Ayuda: ticket de consumo

¿Cómo se usa este ticket?

¿?
  • Selecciona productos del catálogo para agregarlos al carrito. Aquí puedes revisar los artículos, las cantidades y el total a pagar.
  • Elige Venta Directa Mostrador y selecciona la forma de pago (Efectivo, Yape, Plin o Tarjeta) para pasar al cobro. La selección también aparecerá en el formulario de confirmación.
  • Elige una cabina ocupada para cargarle los productos: se descuentan del inventario y se suman a sus consumos para cobrarlos junto con la sesión.
  • Presiona Cobrar / Registrar Venta para continuar. Si cargas el pedido a una cabina, el consumo se registra allí sin abrir un cobro inmediato.

Ayuda: control de cabinas

Funciones disponibles en cada computadora

¿?
  • Iniciar Sesión: elige tiempo libre para medir el uso o tiempo fijo para establecer una duración en minutos y segundos.
  • Agregar tiempo: usa +15m para añadir 15 minutos o + Tiempo para indicar minutos y segundos. También puedes hacerlo si la sesión venció.
  • El cobro de Internet se calcula automáticamente según el precio por hora de la PC y el tiempo que se usó.
  • Agregar consumos: añade productos a la cabina; se descuentan del inventario y se cobran al cerrar la sesión.
  • Cobrar & Cerrar: muestra el total de Internet y consumos para registrar el pago y liberar la computadora.
  • Cancelar sesión sin cobrar: elimina el tiempo y los consumos de esa sesión, devuelve los productos al inventario y no registra una venta.
  • Solo los administradores pueden editar el nombre, la imagen fija y el precio por hora de una cabina libre.
  • Solo los administradores pueden eliminar cabinas libres. Las ventas anteriores se conservan; una cabina ocupada no se puede borrar.
